Benchmark your evaluator

RoboGazeBench tests whether an evaluator finds the right visible failures at the right time. It contains 914 generated clips, including 210 failure-free clips, with human reference events. This guide describes the paper's evaluation protocol. The reports downloadable from this website cover the demonstration clips only, not the full benchmark.

Prepare predictions

Run your evaluator on the benchmark clips and retain the task instruction, clip identifier, original timestamp scale, and predicted events. Export descriptions, temporal spans, dimensions/types, and severity. Keep model, prompts, visual-input policy, and run configuration traceable. Include every clip in the final accounting, including empty reports and parse failures.

Compare methods under the same backbone and its visual-input policy. Use the same reference annotations, matching protocol, and scoring configuration. Do not tune prompts or thresholds on held-out evaluation conditions.

Match events

The reported protocol uses a fixed language judge to score the semantic similarity of each predicted/reference description pair. Hungarian assignment pairs events one-to-one using description similarity multiplied by temporal intersection-over-union. An evaluator's confidence or severity is not a substitute for matching its evidence and timing to a reference.

Report complementary metrics

MetricWhat it measures
Description F1Whether the predicted descriptions identify the reference failures, accounting for missed and invented events
mIoUTemporal overlap of matched event spans
F1 × IoUJoint description and temporal agreement
Clean-clip accuracyFraction of failure-free clips receiving an empty report
Severe-event recallRecovery of severity-4/5 reference events

Record the judge snapshot, scoring settings, and aggregation policy with results. In the paper, results aggregate over the six dimensions and uncertainty intervals use paired bootstrap resampling over source conditions. Keep failures, missing outputs, retries, and compute in the accounting rather than silently dropping difficult clips.

For a new collection without human annotations, use RoboGaze for diagnosis. Event counts alone do not measure evaluator accuracy.
